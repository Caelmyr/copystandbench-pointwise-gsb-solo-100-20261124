# CopyStand Bench｜俯拍校准台

档案照相和文物复制工作在批量开拍前先跑一次标定卡，检查相机焦位、台面光线和平面比例。CopyStand 按拍摄档位组织原照，测量指定位置，把现场人工通过的原照和一处关键细节封存为复核单。

在本目录运行 `./start.sh`，打开 [俯拍校准台](http://127.0.0.1:19903/)。用 `COPYDESK_PORT` 设置本机端口，`./start.sh stop` 停止服务并保留数据卷。也可以按 `requirements.txt` 安装依赖，再用 `python -B -m copydesk` 启动。

1. 新建台位后，给调焦手轮上的整数档位各导入一张标定卡原照。直接打开合成片可体验九档序列、三个检查框和标尺。
2. 选择原照，在固定相机、照明和参考卡的同一序列上框选需要复查的位置。可切换、重画或移除检查框。深底黑蓝覆盖和近白红覆盖可帮助找欠曝、过曝。
3. 读整照亮度直方图，检查选区的原分辨率清晰度、灰阶跨度和九格亮度中位数。平坦中性卡可检查各通道的像素均值与近纯白比例。
4. 在原照中点选同一平面的标尺两端并输入实际距离，检查框读出毫米尺度。全组共用像素比例时应保持机位不变。
5. 所选框的清晰度表可跳转到逐档原照。可以把当前考察档与已经采用档的同框裁片并排看，或下载独立裁片、整照或联系表。
6. 人工采用一档原照和一处检查框后封存。打开复核单可以看当时的整照、关键细节和读数。ZIP 包含转正原照、未缩放裁片、坐标、读数与哈希。
7. 照片准备页可生成另一次处理的结果，在档位空闲且尺寸匹配时送回校准台。送入结果标记照片准备来源。

导入格式为单帧 PNG、JPEG 或 TIFF。像素尺寸以 EXIF 转正后为准，工作像素以 RGB PNG 保存，透明像素铺白，每组照片必须同尺寸。单张上传最多 12 MiB、约 320 万像素，整组 25 档且照片存储量到 160 MiB，每组最多八个检查框，短边至少 24 像素。坐标以转正图像像素为基准，裁片边界是左上包含、右下不包含。

清晰度读数是检查框内部灰度拉普拉斯响应的均方值，适合固定照明、图案和相机的同卡同框比较。它受纹样、局部对比、曝光和噪声影响。局部亮度与近白的像素读数供看现场布光使用。颜色温度和照度的物理标定需对应仪器。共享标尺按平面统一倍率计算。示范原照由代码生成，图案和离焦属于合成数据。
